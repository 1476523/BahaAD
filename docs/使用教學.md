## 1. 安裝與啟動

1. 到 [Releases](https://github.com/1476523/BahaAD/releases) 下載 `BahaAD-<版本>-win64.zip`。
   - 想要穩定 → 抓標 **`Latest`** 的(正式版發布後才有)。
   - 想試 Beta → 抓標 **`Pre-release`** 的最新一個。
2. 解壓縮到你想放的資料夾,例如 `C:\BahaAD\`。**不要**放在 `C:\Program Files\` 這種需要
   管理員權限才能寫入的位置(自我更新會失敗)。
3. 雙擊 `BahaAD.exe`。

啟動後:

- 右下角系統匣(工作列右側)會出現 BahaAD 圖示。
- 預設瀏覽器會自動打開網頁控制台 `http://127.0.0.1:5996`。
- 第一次啟動時,Windows 可能會跳一次使用者帳戶控制(UAC)對話框,詢問是否允許建立防火牆
  規則 —— 這是為了讓你能用同區網的手機/其他電腦連進來管理。按「是」即可;按「否」也能用,
  只是之後只能從這台電腦本機開。

之後要開控制台,右鍵點系統匣圖示 →「開啟網頁」。要關閉程式,右鍵 →「結束」。

## 2. 建立網頁介面帳號密碼

第一次進網頁會要求你**設定一組帳號與密碼**。

- 這組帳密是網頁介面**唯一的存取保護**(因為網頁伺服器預設開放區網)。
- **忘記密碼只能重置整個 BahaAD**(見第 16 節),請用密碼管理器妥善保存。
- 設定完成會自動登入,接著進入下一步。

## 3. 登入動畫瘋帳號

設定完帳密後,會出現「要現在登入巴哈姆特動畫瘋嗎?」的提示頁。也可以之後從
**設定 →「動畫瘋登入」** 收納區塊再設定。

**為什麼要登入:** 下載 VIP / 付費會員限定或高畫質的內容,需要你自己有效的動畫瘋付費帳號。
BahaAD 只是把你自己有權觀看的內容下載到本機。

登入表單需要:

| 欄位 | 說明 |
|---|---|
| 帳號 | 你的巴哈姆特帳號 |
| 密碼 | 你的巴哈姆特密碼 |
| 兩步驟驗證密鑰 | **選填**。若你的帳號開了兩步驟驗證,填入 TOTP 密鑰(不是六位數字,是設定 2FA 時給的那串長字母),BahaAD 才能自動完成登入 |

送出後 BahaAD 會在背景開一個瀏覽器視窗完成登入並取得 Cookie,進度頁會顯示狀態。

**環境偽裝(自動):** 首次設定帳密後,BahaAD 會在背景自動採集一次你這台電腦的瀏覽器指紋
(User-Agent / JA3 / Akamai),用來讓自動化請求看起來跟一般瀏覽器一致、降低被站方風控
誤擋的機率。這個過程不需要你操作,設定頁「動畫瘋登入」區可看到指紋狀態,也可以手動重新
採集或清除。

所有帳號、密碼、2FA 密鑰、Cookie、指紋都以 Windows DPAPI **加密**儲存在你自己的電腦上
(綁定你的 Windows 使用者帳戶),不會離開你的電腦。

## 4. 瀏覽與搜尋番劇

左側導覽列:

| 入口 | 內容 |
|---|---|
| **首頁** | 本季新番輪播 |
| **本季新番 / 近期熱播 / 最新上架** | 對應動畫瘋官方各榜單 |
| **搜尋** | 關鍵字搜尋番劇 |
| **排行榜** | 熱門排行 |
| **訂閱列表** | 你訂閱(鈴鐺)過的番劇 |
| **下載列表** | 你下載過的番劇 |

點任一張番劇卡片進入**番劇詳細頁**,可看到簡介以及依官方分類(正片 / 電影 / 特別篇 / …)
排列的集數清單。

> **中文配音集數**預設**不顯示**。若要顯示,到 **設定 →「番劇頁顯示」→ 勾「顯示中文配音集數」**。

## 5. 下載單集或多集

在番劇詳細頁的集數清單上:

| 操作 | 選取方式 |
|---|---|
| 單選 | 點一集 |
| 加選 / 減選 | `Ctrl` + 點 |
| 區間選取 | 點第一集,再 `Shift` + 點最後一集 |
| 拖曳連續選取 | 在集數格上按住拖過去 |

選好之後按「下載選取集數」。也有「整個番劇 全部下載」的按鈕(同樣會套用「不含中文配音集數」
的設定)。

**沒有訂閱**的番劇按下載時,會用網頁內的輸入框詢問要用什麼資料夾名稱。

畫質由 **設定 → `preferred_quality`** 決定(留空 = 自動選最高位元率;或填 `1080p` / `720p` /
`540p` / `360p`)。

下載檔案存到 **設定 → `download_dir`**(預設 `~/Downloads/BahaAD`)。

### 未登入 / 免費番劇

若沒有登入動畫瘋帳號:

- **VIP / 付費會員限定**的集數無法下載,失敗卡片會明確說明「需要登入有 VIP 的帳號」。
- **免費番劇**:BahaAD 會嘗試走「看廣告」交握流程取得播放清單。此功能為預設開啟
  (設定裡的 `guest_download_enabled`),站方若調整廣告驗證方式可能失效 —— 最穩定的方式
  仍是登入你自己的帳號。

## 6. 訂閱鈴鐺與自動下載

在**番劇卡片**或**番劇詳細頁**點 **🔔 鈴鐺** 即可訂閱。訂閱後:

- BahaAD 依官方週期表的時段,在新集數上架後自動下載。
- 全域檢查週期由 **設定 → `check_interval_minutes`**(預設 30 分鐘)決定。
- 再點一次鈴鐺 = 取消訂閱。取消訂閱會保留你手動設定過的分類 / 改名,並清掉該番劇的
  孤兒紀錄。

訂閱過的番劇都列在左側「**訂閱列表**」。

---

## 7. 排程清單:分類資料夾與自訂時段

排程清單以「**訂閱列表頁右側的浮動面板**」形式存在(沒有獨立整頁)。在這裡逐項調整:

| 欄位 | 作用 |
|---|---|
| **分類 (tag)** | 這是**真的下載子資料夾**:`下載目錄/<分類>/<番劇名>/…`,可用 `/` 分多層。留空時 BahaAD 依該番劇首播季度自動歸到季別資料夾(例:`2026/07 七月新番/`),面板會用灰字提示自動分類結果,但不寫進排程檔 |
| **改名 (rename)** | 下載資料夾用這個名字,而不是站方原始標題 |
| **自訂時段** | 星期 + 時:分下拉。設了就用你指定的時段檢查這一部,沒設就「跟隨全域週期」。三個值要嘛全填、要嘛全空 |

加入 / 取消追蹤一律用卡片上的鈴鐺,面板沒有「新增 / 刪除」鈕。

---

## 8. 下載佇列與失敗重試

左側「**下載列表**」→ 進入後可看到:

- 進行中的下載**即時進度**。
- 失敗的項目會顯示**失敗原因**(例如「未登入」「VIP 限定」「解析失敗」)。
- 失敗項目可**一鍵重試**。

同時下載幾部由 **設定 → `max_concurrent_downloads`**(預設 2,上限 5)決定;
單一影片同時抓幾個片段由 `max_concurrent_segments`(預設 4,上限 5)決定。

## 9. 官方公告監視

BahaAD 會定期掃描動畫瘋官方公告,自動解析並處理:

- **暫停更新 / 延後更新 / 同時加更 / 暫時下架 / 其他** 五類公告。
- 偵測到時可自動調整對應番劇的排程,並(若有設定)發通知。

在左側「**官方公告**」入口可看歷史公告、手動處置、以及機動調整紀錄。
相關開關在 **設定 →「監視公告」** 區(是否監視、是否依公告動態調整排程、公告保留天數)。

**番劇完結自動偵測:** 訂閱的番劇連續一週從週期表消失、且沒有「下架」公告時,BahaAD
判定它已完結,會發「番劇完結」通知並停止對它的檢查。

## 10. 新番快訊

> ⚠️ **此功能尚未經過實際測試。** 目前只做過模擬測試,要等到 2026 年 10 月秋季新番
> 資訊實際發布後才能端到端驗證。使用時請留意行為可能與預期不符,歡迎回報。

每季(1 / 4 / 7 / 10 月)動畫瘋會發布「下一季新番節目資訊」。BahaAD 偵測到後,會抓官方
GNN 文章整理成「按星期 + 更新時間排序」的新番清單,入口在右側「官方公告」下方的「**新番快訊**」。

- 每部新番可以「**追蹤**」(新番版的訂閱)。
- 番劇真的上架後,BahaAD 會用原始名稱比對出真正的集數編號,把追蹤自動轉成正式訂閱並
  開始下載。

## 11. 內建播放器

在番劇詳細頁,對**已下載**(藍框,代表有紀錄且檔案還在)的**單一**集數,會出現「▶ 播放」鈕。

- 浮層播放器:上一話 / 倒轉 10 秒 / 快轉 10 秒 / 下一話 / 投放。
- 方向鍵 ±10 秒,`Esc` 或 ✕ 關閉,會記住播放進度。
- 在本機 / 區網直接串流;從外部(反向代理)連進來時自動走 HLS。
- 投放使用瀏覽器內建的 Remote Playback(Safari / iOS 的 AirPlay、桌面 Chrome 的 Chromecast),
  有可投放裝置時才顯示投放鈕。

原始 mp4 檔案被刪掉後,對應的播放快取也會一併清除。

## 12. Telegram / Discord 通知

**設定 →「通知設定」**:

1. 填入 **Telegram Bot Token + Chat ID**,或 **Discord Webhook URL**(可只設一個,也可兩個都設)。
2. 勾選要接收哪些**類別**的通知:下載完成、下載失敗、各類公告、番劇完結、有新版本。
3. **通知範本**可自訂 —— 「通知設定」的範本編輯頁提供八個可編輯類別、預覽、還原預設。

通知內容完全是你自己的追蹤 / 下載資訊,只送到你自己設定的 Telegram / Discord,不經過
任何第三方。發送歷史可在「通知」入口查閱、失敗可重送。

## 13. 設定項目說明

**設定** 頁(左側齒輪)常用欄位:

| Key | 預設 | 說明 |
|---|---|---|
| `preferred_quality` | 空(自動最高) | 畫質偏好,例 `720p` |
| `download_dir` | `~/Downloads/BahaAD` | 下載輸出目錄 |
| `check_interval_minutes` | 30 | 全域檢查新集數週期 |
| `max_concurrent_downloads` | 2 | 同時下載幾部(上限 5) |
| `max_concurrent_segments` | 4 | 單一影片同時抓幾個片段(上限 5) |
| `download_cooldown_seconds` | 0 | 片段批次間節流秒數 |
| `sn_query_cooldown_seconds` | 0 | 查詢中繼資料間節流秒數 |
| `max_retries` | 3 | 單一片段重試次數 |
| `cookie_warmup_interval_hours` | 6 | 檢查登入態週期 |
| `version_check_interval_hours` | 12 | 檢查新版本週期 |
| `web_port` | 5996 | 網頁介面連接埠(**改完要重啟 BahaAD 才生效**) |

其他區塊:動畫瘋登入、番劇頁顯示、監視公告、通知設定、GitHub 帳號連結、錯誤自動回報 /
即時統計開關。每個數字 / 文字欄位旁有「還原這一項」小按鈕。

側欄版本號右側有「**隱私權政策**」按鈕,點開即時顯示完整隱私權說明。

## 14. 用手機或其他裝置連進來

網頁伺服器預設監聽區網(`0.0.0.0`),所以同一個區網(同一個 Wi-Fi / 路由器)下的其他裝置
可以連進來管理:

1. 查出跑 BahaAD 那台電腦的區網 IP(在那台電腦開 `cmd` 打 `ipconfig`,看「IPv4 位址」,
   通常長得像 `192.168.x.x`)。
2. 在手機瀏覽器開 `http://192.168.x.x:5996`。
3. 用你設定的帳號密碼登入。

若連不進來,通常是第一次啟動時的防火牆 UAC 按了「否」—— 到 **設定** 頁上方的橫幅按
「允許」重新建立防火牆規則(會再跳一次 UAC)。

> 只想從本機用、想完全避開防火牆的極少數人:可自行把 DB 的 `web_lan_access` 設為 `False`,
> 伺服器就只監聽 `127.0.0.1`。一般人不需要動它。

## 15. 更新

BahaAD 有兩條獨立的更新機制:

1. **版本更新提示**:定期查 GitHub Release,有新版時在網頁介面顯示提示。Beta 版預設會
   提示下一個 Beta,正式版預設只提示正式版 —— 可在 **設定 →「版本更新提示」** 切換。
2. **線上差異更新**:自動下載有變動的檔案、透過小幫手程序重啟套用。
   - **一般更新**:顯示橫幅 + 提醒視窗,可「稍後再說」。
   - **重點更新**:套用前會鎖住網頁介面(背景排程 / 下載不受影響),完成重啟後解除。

手動更新:直接下載新版 zip,解壓縮覆蓋舊資料夾即可(你的設定與資料庫存在
`%LOCALAPPDATA%\BahaAD`,不在程式資料夾,覆蓋不會遺失)。

## 16. 忘記密碼 / 完全重置

- **忘記密碼**:網頁登入頁的「忘記密碼」→ 只清掉憑證(網頁帳密、動畫瘋登入),其他保留。
- **完全重置**:設定頁的「完整重置」→ 刪掉整個 `bahaad.db`(所有設定、訂閱、下載紀錄、
  排程),回到全新狀態。**已下載的影片檔案不會被刪。**

出於安全考量(避免透過反向代理從外部觸發),首次設定 / 忘記密碼 / 完全重置這幾個高風險
動作,在**未登入**狀態下需要輸入一組**只會出現在該電腦系統匣通知**的驗證碼 —— 也就是
必須有人真的坐在那台電腦前面才能完成。

匿名啟動識別碼(見隱私權說明)存在獨立檔案,完全重置**不會**清掉它。

## 17. 常見問題

**Q. 一進首頁就一直轉圈 / 連線被重置?**

A. 首頁一次會載入很多張封面圖。若某個外部 CDN 圖片卡住可能拖慢整頁,重新整理通常就好。
持續發生請開 Issue 附上「錯誤自動回報」是否開啟。

**Q. 網頁整個打不開 `ERR_CONNECTION_ABORTED` / 用 AdGuard 才這樣?**

A. AdGuard for Windows 若把「本機(loopback)連線」也納入過濾,會攔掉 BahaAD 的本機網頁
伺服器。**AdGuard →「設定 > 應用程式設定 > 進階設定」→ 關閉「過濾本機主機(loopback)」**。
(WFP 模式預設放過本機連線,socket 層過濾模式預設連本機也攔——切換過濾方式後才出現多半
是這個原因。)也可以改用電腦的區網 IP 開,例如 `http://192.168.x.x:5996/`。

**Q. 下載一直失敗,顯示「裝置驗證異常」(code 1007)?**

A. 通常是登入 Cookie / device_id 對不上。到 **設定 →「動畫瘋登入」** 重新登入一次。

**Q. VIP 番劇下載失敗說要登入,但我已經登入了?**

A. Cookie 可能過期。重新登入動畫瘋帳號;若你的帳號沒有現行的付費會員資格,VIP 內容本來
就無法下載。

**Q. 下載目錄可以放網路磁碟機 / NAS 嗎?**

A. 可以,把 `download_dir` 設成對應路徑即可。第一次下載時 BahaAD 會自動建立目錄。

**Q. 可以同時開很多條下載加速嗎?**

A. `max_concurrent_downloads` 和 `max_concurrent_segments` 上限都是 5,填更大也會被夾回 5。
開太多容易被站方風控,建議維持預設。

**Q. 為什麼看不到某些集數(中文配音)?**

A. 預設隱藏。**設定 →「番劇頁顯示」→ 勾「顯示中文配音集數」**。

**Q. 要怎麼備份我的設定?**

A. 複製整個 `%LOCALAPPDATA%\BahaAD` 資料夾。

**Q. 移到新電腦後動畫瘋登入失效?**

A. 帳密 / Cookie 用 DPAPI 加密、綁定原本那台電腦的 Windows 帳戶,換機器解不開是正常的,
在新電腦重新登入一次即可。
