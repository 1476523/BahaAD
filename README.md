# BahaAD

**巴哈姆特動畫下載器 Bahamut Animation Downloader**

自動追蹤、排程檢查、下載巴哈姆特動畫瘋的番劇，並提供一個電腦／手機瀏覽器都能用的
網頁控制台。目前僅支援 Windows。

> ⚠️ **目前只有 Beta 版，正式版尚未發布。**
> Beta 版主要功能都已到位並實際測試過，但仍在收集回饋、修穩定性，設定與行為可能還會
> 變動。歡迎到 [Issues](https://github.com/1476523/BahaAD/issues) 回報問題。

---

## Beta 版 vs 正式版

| | Beta 版 | 正式版 |
|---|---|---|
| 版本號 | `0.y.z`（現在是 `v0.0.1`） | `1.0.0` 起 |
| 在 [Releases](https://github.com/1476523/BahaAD/releases) 上 | 標「Pre-release」徽章 | 標「Latest」 |
| 適合 | 想先試新功能、願意回報問題 | 想要穩定、不常更新 |

**怎麼抓對版本：**

- 想用穩定版 → 抓 Releases 頁最上面標 **`Latest`** 的那個（正式版發布後才會有）。
- 想用 Beta → 抓標 **`Pre-release`** 的最新一個。
- 工具內建的「版本更新提示」：Beta 版預設會提示下一個 Beta，正式版預設只提示正式版，
  都可以在設定頁自行切換。

## 安裝

1. 到 [Releases](https://github.com/1476523/BahaAD/releases) 下載
   `BahaAD-<版本>-win64.zip`。
2. 解壓縮到你想放的資料夾（例如 `C:\BahaAD\`）。
3. 雙擊 `BahaAD.exe`。

不需要安裝 Python，也不需要額外的執行環境。

## 第一次啟動

1. 啟動後右下角系統匣會出現 BahaAD 圖示，瀏覽器會自動打開網頁控制台
   （預設 `http://127.0.0.1:5996`）。
2. 第一次會要你**建立一組網頁介面的帳號密碼**——這組密碼是網頁介面唯一的存取保護，
   忘記只能重置整個 BahaAD，請妥善保管。
3. 接著可以選擇要不要現在登入自己的巴哈姆特動畫瘋帳號。**下載 VIP／付費會員限定或
   高畫質的內容，需要登入你自己有效的動畫瘋付費帳號。**
4. 之後就從系統匣圖示的「開啟網頁」進入控制台管理。

> 網頁伺服器監聽區網，所以你也能用同一個區網下的手機瀏覽器連進來管理
> （網址是執行 BahaAD 那台電腦的區網 IP ＋ `:5996`）。安全性靠你設的帳號密碼。

**功能導覽見 [功能介紹](docs/功能介紹.md)；完整操作步驟見 [使用教學](docs/使用教學.md)。**

## 主要功能

- **瀏覽番劇**：本季新番、近期熱播、最新上架、關鍵字搜尋，番劇詳細頁含分類集數清單。
- **訂閱鈴鐺**：一鍵訂閱，之後依官方週期表的時段自動下載新集數。
- **集數多選下載**：單選／Ctrl 加選／Shift 區間／拖曳連續。
- **手動補抓**、**下載佇列即時進度**、**失敗一鍵重試**。
- **排程清單管理**：每部番劇可設分類子資料夾、改名、自訂檢查時段。
- **官方公告監視**：自動解析延播／暫停／下架公告並調整排程。
- **番劇完結自動偵測**。
- **新番快訊**：每季新番資訊發布時整理成可追蹤清單（此功能尚未實測，需等 2026 年
  10 月秋季新番才能端到端驗證）。
- **內建播放器**：已下載的集數可直接在網頁介面播放（含手機、投放）。
- **Telegram / Discord 通知**（可自訂範本）。
- **工具內更新提示**、自我更新。
- 淺／深色主題、常駐系統匣。

## 從原始碼建置（進階）

需要 Python 3.11+、Windows、MSVC（Visual Studio Build Tools）。

```powershell
python -m venv .venv
.venv\Scripts\pip install -e ".[dev]"
.venv\Scripts\python scripts\build.py
```

產出在 `build_nuitka\main.dist\BahaAD.exe`。

> 本 repo 是正式散布用的乾淨快照，不含開發歷史。專案的授權後端（負責 GitHub 連結、
> star 查詢、匿名統計彙總）是獨立部署的服務，不隨用戶端散布，因此不在本 repo 內；
> 缺少它不影響用戶端的下載、排程等所有功能。
